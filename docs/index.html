🚀 기본 사용법

  1. URL 접속 후 즐겨찾기 등록
  2. 좌측 메뉴에서 기능 선택
  3. 입력한 데이터는 자동 저장됩니다

📆 주간 스케줄 (근태 + 업무)

  • 팀원 1명 = 1행. 요일 칸에 그 날 업무를 넣습니다
  • 칸 클릭 또는 + → 그 팀원·그 날짜로 업무 추가 (수행일이 자동 입력됩니다)
  • 업무는 수행일(시작일) 기준으로 해당 요일 칸에 표시됩니다. 마감일은 선택 입력입니다
  • 업무 제목 클릭 → 전체 내용 보기 / 체크박스 → 완료
  • 근태는 출장·휴가·교육·기타만 칩으로 표시됩니다. 표시가 없으면 출근입니다
  • 근태를 넣으려면 칸에 마우스를 올려 나타나는 [근태] 버튼을 누르세요
  • 수행일이 없는 업무는 팀원 칸에 📋 미지정 배지로 모아 표시됩니다
  • 🔴 지원 필요로 등록된 업무가 있으면 그 팀원 행이 붉게 점멸합니다

🗓️ 월간 근태

  • 한 달 전체 근태를 달력 형식으로 봅니다 (업무는 표시되지 않습니다)
  • 날짜 클릭 → 그 날 팀원 전체 근태를 한 번에 입력
  • 버튼을 다시 누르거나 출근을 누르면 입력이 해제됩니다
  • 일요일과 공휴일은 숫자가 빨간색, 배경이 연한 빨간색으로 표시됩니다
  • 하단에서 팀원별 월간 근태 집계를 확인할 수 있습니다

👥 팀원 관리

  • 표의 각 칸을 클릭하면 즉시 수정 가능 (Enter 저장 / Esc 취소)
  • 직책: 파트장 / 책임연구원 / 선임연구원
  • 역할 (메인 업무): 담당 업무를 짧게 적으면 대시보드 메인 업무에 표시됩니다

✅ 업무 관리 팁

  • 지원 필요 체크 시 🔴 표시되고 대시보드에 경고가 뜹니다
  • 마감 2일 이내면 ⏰ 로 강조됩니다
  • 상세 모달에서 완료 처리 / 수정 / 삭제 가능
  • 대시보드 팀원표의 진행중·완료 업무 칸을 클릭해도 목록이 열립니다

📊 대시보드

  • 타이틀에 오늘 날짜, 근태 현황과 업무 현황이 구분되어 표시됩니다
  • 메인 업무 = 팀원 관리에 입력한 역할입니다. 주간 스케줄의 업무와는 별개입니다
  • 지원 필요 = 주간 스케줄에서 "지원 필요"로 체크된 업무가 있는 팀원 (붉게 점멸)
  • 비고 = 다가오는 근태 일정. 휴가 D-3, 4일 이상이면 장기휴가 D-5 (4일)

💾 데이터 저장 위치

  • 좌측 하단 상태 표시로 현재 저장 방식을 확인할 수 있습니다
    • 🟢 실시간 공유 중 — 파트원 전체가 같은 데이터를 봅니다. 다른 사람이 입력하면 새로고침 없이 내 화면도 바뀝니다.
    • ⚪ 이 브라우저에만 저장 — 공유되지 않습니다. Firebase 연결이 필요합니다.
    • 🟡 연결 중 / 🔴 연결 오류 — 네트워크 또는 권한 문제입니다.
  • 실시간 공유 모드에서도 마지막 데이터가 브라우저에 캐시되어, 네트워크가 끊겨도 화면은 유지됩니다.
  • 공유 모드는 로그인 없이 링크만으로 사용하도록 설정되어 있습니다.
  • 데이터 백업이 필요하면 Firebase 콘솔 → Realtime Database → 데이터 에서 우측 ⋮ 메뉴의 JSON 내보내기를 사용하세요. (파트장 권한 필요)
  • ⚠️ 삭제한 데이터는 되돌릴 수 없습니다. 팀원·업무 삭제 시 확인 후 진행하세요.
  • 연결 설정 방법은 저장소의 docs/SETUP-FIREBASE.md 문서를 참고하세요.
