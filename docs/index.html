🚀 기본 사용법

📆 주간 캘린더

  • 요일 칸 클릭 → 근태 선택 (출장/휴가/교육/기타)
  • 빈칸 = 출근 (별도 입력 불필요)
  • 주간 할 일 칸의 빈 곳 클릭 → 해당 팀원 업무 바로 추가
  • 할 일 제목 클릭 → 전체 내용 확대 보기 (긴 내용은 … 로 줄여서 표시됩니다)
  • ◀ ▶ 로 주 이동, "오늘" 로 현재 주 복귀

✅ To Do

  • 상단 팀원별 업무 현황 표에 진행중/완료/지원필요 업무가 내용으로 표시됩니다
  • 내용이 길면 …, 여러 건이면 +N 으로 표시 → 칸을 클릭하면 전체 목록이 모달로 열립니다
  • 모달에서 완료 처리 / 수정 / 삭제를 바로 할 수 있습니다
  • 표 우측 + 버튼으로 해당 팀원에게 업무 바로 배정
  • 지원 필요 체크 시 대시보드에 경고 표시
  • 필터: 전체 / 진행중 / 완료 / 지원필요 / 마감임박

👥 팀원 관리

  • 표의 각 칸을 클릭하면 즉시 수정 가능 (인라인 편집)
  • Enter = 저장, Esc = 취소
  • 직책: 파트장 / 책임연구원 / 선임연구원

📢 공지사항

  • 파트 공지, 회의록, 메모 공유
  • 각 카드의 수정 / 삭제 버튼 사용

⚠️ 데이터 저장 위치 (중요)

  • 데이터는 접속한 브라우저에만 저장됩니다 (localStorage)
  • 따라서 다른 팀원에게 자동 공유되지 않습니다
  • 공유가 필요하면 좌측 💾 백업 저장 → 파일 전달 → 상대방이 📂 백업 불러오기
  • 실시간 공동 편집이 필요하면 서버 연동이 필요합니다 (파트장 문의)
  • 브라우저 캐시 삭제 시 데이터가 사라지므로 주기적 백업 권장
