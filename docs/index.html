📖 사용 가이드

🚀 시작하기

  1. URL 접속 후 브라우저 즐겨찾기 등록
  2. 좌측 메뉴에서 원하는 기능 선택
  3. 모든 데이터는 브라우저 로컬 스토리지에 자동 저장됩니다

📆 주간 캘린더

  • 셀 클릭 → 근태 상태 선택 (출장/휴가/교육/기타)
  • 빈 칸 = 출근 (별도 입력 불필요)
  • 메모 입력 가능 (출장지, 사유 등)
  • ◀ ▶ 버튼으로 주간 이동, "오늘" 클릭으로 복귀

📊 대시보드

  • 팀원별 근태, 미완료 업무 현황 한눈에 확인
  • 🔴 지원 필요 표시된 팀원은 업무 과부하 상태
  • 기준: 미완료 Todo 5건 이상 또는 "지원필요" 체크된 항목 존재 시

✅ To Do

  • 팀원별 할 일 등록 (담당자 선택 필수)
  • 우선순위: 높음 / 보통 / 낮음
  • 지원 필요 체크 시 대시보드에 경고 표시
  • 필터: 전체 / 진행중 / 완료 / 지원필요

📢 공지사항

  • 파트 내 공유할 공지, 메모, 안내사항 작성
  • 제목과 내용을 입력하여 게시

👥 팀원 관리

  • 이름, 직책(드롭다운), 사번, 이메일, 색상 입력
  • 수정: 해당 팀원 "수정" 버튼 → 폼에 정보 로드 → 저장
  • 삭제: 관련 일정/할 일도 함께 삭제됨

⚠️ 주의사항

  • 데이터는 브라우저 로컬 스토리지에 저장됩니다
  • 브라우저 캐시 삭제 시 데이터 초기화
  • 다른 PC에서는 별도 데이터입니다
