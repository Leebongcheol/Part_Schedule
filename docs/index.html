📖 사용 가이드

🚀 시작하기

  1. URL에 접속하여 북마크 등록
  2. 좌측 메뉴에서 원하는 기능 선택
  3. 데이터는 브라우저 로컬 스토리지에 저장됩니다

📆 주간 캘린더

  • 셀 클릭 → 상태 선택 팝업이 나타남
  • 상태 종류: 출근, 출장, 휴가, 공가, 재택, 교육
  • 이전/다음 주 버튼으로 주간 이동
  • 오늘 버튼으로 현재 주 복귀
  • 메모 입력 후 확인 버튼 클릭으로 저장

📊 대시보드

  • 전체 인원, 출장/휴가/재택 인원 현황 카드
  • 업무부하 상태 한눈에 확인
  • 🔴 지원 필요: 일정 10건 이상 또는 미완료 Todo 5건 이상

✅ To Do 관리

  • 할 일 추가: 제목, 담당자, 우선순위, 마감일 입력
  • 완료 처리: 체크박스 클릭
  • 필터: 전체 / 진행중 / 완료
  • 진행률: 하단 프로그레스바로 전체 진행률 확인

👥 팀원 관리

  • 추가: 이름, 부서, 색상 입력 후 추가 버튼
  • 삭제: 해당 팀원 행의 삭제 버튼
  • 팀원별 업무부하 상태도 확인 가능

💾 데이터 관리

  • 내보내기: 좌측 하단 📤 클릭 → JSON 파일 다운로드
  • 가져오기: 좌측 하단 📥 클릭 → JSON 파일 선택
  • 팀원 간 데이터 공유에 활용

⚠️ 주의사항

  • 데이터는 브라우저 로컬 스토리지에 저장됩니다
  • 브라우저 캐시 삭제 시 데이터가 초기화됩니다
  • 정기적으로 내보내기를 통해 백업하세요
  • 다른 PC에서 사용 시 가져오기로 데이터 복원
