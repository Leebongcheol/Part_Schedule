# 파트 스케줄표 📅

팀원 10명 내외가 사용하는 간편한 주간 스케줄 공유 웹앱입니다.  
GitHub Pages로 배포하여 **URL 하나만 공유**하면 누구나 접근 가능합니다.

## 🔗 사용 방법

1. 아래 URL을 팀원에게 공유 (배포 후 생성됨):
   ```
   https://<your-username>.github.io/Part_Schedule/
   ```
2. 팀원 각자 **북마크** 해두고 사용
3. 데이터는 각자 브라우저 `localStorage`에 저장됨

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 주간 캘린더 | 월~금 주간 뷰, 이전/다음 주 탐색 |
| 상태 관리 | 출근 / 출장 / 휴가 / 공가 / 재택 / 교육 |
| 팀원 관리 | 팀원 추가/삭제, 부서·색상 지정 |
| 셀 클릭 편집 | 날짜+팀원 셀 클릭 → 상태 선택 |
| 메모 | 각 일정에 짧은 메모 추가 가능 |
| 데이터 공유 | JSON 내보내기/가져오기로 팀원 간 데이터 동기화 |
| 인쇄 | 인쇄 최적화 스타일 포함 |

## 🚀 GitHub Pages 배포 방법

### 방법 1: GitHub 설정에서 직접 (가장 쉬움)

1. 이 레포지토리를 GitHub에 push
2. GitHub 레포 → **Settings** → **Pages**
3. Source: **Deploy from a branch**
4. Branch: `main` (또는 `master`), Folder: `/docs`
5. **Save** 클릭
6. 1~2분 후 URL 생성 완료!

### 방법 2: GitHub Actions (자동 배포)

`.github/workflows/deploy.yml`이 포함되어 있으면 push 시 자동 배포됩니다.

## 📂 파일 구조

```
docs/

├── style.css     # 스타일시트
├── app.js        # 앱 로직 (vanilla JS)
└── README.md     # 이 파일
```

## 💾 데이터 관리

- **저장 위치**: 각 사용자의 브라우저 localStorage
- **공유 방법**: JSON 내보내기 → 파일을 팀원에게 전달 → 가져오기
- **초기 데이터**: 최초 접속 시 샘플 팀원 6명이 자동 생성됨

### 팀 전체 동기화 팁

1. 한 명이 팀원 목록 + 이번 주 스케줄을 입력
2. **데이터 내보내기** (JSON 다운로드)
3. 팀 채팅방에 JSON 파일 공유
4. 나머지 팀원들이 **데이터 가져오기**로 불러오기

## 🖥️ 기술 스택

- **HTML/CSS/JS** 순수 정적 파일 (서버 불필요)
- **localStorage** 브라우저 내장 저장소
- **의존성 없음** (npm install 불필요)
- **어떤 브라우저**에서든 동작 (Chrome, Edge, Firefox, Safari)

## ⚠️ 참고사항

- 브라우저 캐시/데이터 삭제 시 일정 데이터가 초기화됩니다
- 중요 데이터는 주기적으로 JSON 내보내기로 백업하세요
- 다른 PC/브라우저에서는 별도로 데이터를 가져와야 합니다
